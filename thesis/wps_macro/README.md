# WPS 论文格式宏

这个目录里提供了一份可直接导入 WPS VBA 的宏脚本：[format_guangxi_thesis.bas](./format_guangxi_thesis.bas)。

适用场景：

- 论文主体内容已经基本定稿
- 但当前 `.docx` 的段落样式比较乱，很多内容是“直接格式”
- 需要按广西大学本科论文规范，统一封面、摘要、目录、正文标题、正文、参考文献、致谢、页边距、行距和页码

## 使用方法

1. 先备份你的原始论文，例如另存一份 `第六版-格式修正版.docx`。
2. 用 WPS 文字打开论文。
3. 打开 `开发工具 -> 宏 -> VBA 编辑器`。
4. 在 VBA 工程里导入 `format_guangxi_thesis.bas`。
5. 运行宏 `FormatGuangxiUniversityThesis`。
6. 宏执行完成后，更新一次域/目录，并检查分页效果。

## 宏会自动处理什么

- 统一 A4、上下 2.54cm、左右 2.2cm
- 将封面、摘要、英文摘要、目录、正文、参考文献、致谢按规则重设字体字号
- 将正文改为固定值 20 磅行距
- 识别 `第一章 / 1.1 / 1.1.1 / 1.1.1.1` 这类标题并重设层级
- 识别 `图1-1 ...`、`表3-2 ...` 这类题注并统一格式
- 重建目录为自动目录
- 将前置部分设置为罗马页码，正文从阿拉伯数字 `1` 开始
- 删除封面最前面的“第六版”这类版本标记

## 仍建议人工复查的地方

- 英文摘要题目是否完整存在
- 公式是否真的是“公式居中，编号右对齐”
- 表格内部字体、行高、边框是否满足学院要求
- 少数以 `表3-1 ...` 开头但其实是正文说明句的段落，是否被误判
- 图片与题注是否发生跨页

## 结合你这份论文的已知情况

当前这份 [第六版 (1).docx](../第六版%20(1).docx) 的主要问题不是内容本身，而是：

- 几乎所有段落都没有结构化样式
- 当前整篇文档基本只有 1 个节，页码规则不符合论文前置部分/正文分离的常见做法
- 目录现在更像手工列出的文本，不是自动目录

所以这份宏的核心思路是“重新识别段落角色，再统一套格式”，而不是依赖你现有文档里的样式名。
